# 課前準備：三步建好你的 LLM Wiki

**全程不需要安裝任何軟體、不需要打指令**，用瀏覽器就能完成，預計 10 分鐘。

做完之後你會有：

- ✅ 一個自己的 `llm-wiki` repo（內含 `index.md` 和 `wiki/`，已經幫你建好）
- ✅ 一串 `ghp_` 開頭的 token（n8n 用的鑰匙）
- ✅ 一份改好帳號的 n8n workflow json

---

## 步驟 1：註冊 GitHub 帳號

已經有帳號的話跳過這步。

1. 打開 https://github.com/signup
2. 填 email、設定密碼、取一個帳號名稱（英數字，之後會出現在網址裡）
3. 到信箱收驗證信，輸入驗證碼

> 📝 把你的**帳號名稱**記下來，步驟 4 會用到。

---

## 步驟 2：用 Template 建立你的 Repo

不用手動建任何檔案——老師已經把骨架做成範本，按幾個鈕就複製一份到你帳號下。

1. 打開課程範本 repo（網址老師會提供，長得像
   `https://github.com/<老師帳號>/llm-wiki-template`）

2. 點右上角綠色的 **Use this template** → **Create a new repository**

3. 填寫：

   | 欄位 | 填什麼 |
   | --- | --- |
   | Repository name | **`llm-wiki`**（請照這個名字填，之後設定才對得上） |
   | Description | 可留空 |
   | Public / Private | 選 **Private** |

4. 點 **Create repository**

完成後你會進到自己的新 repo，裡面應該有：

```
📁 docs
📁 n8n
📁 wiki
📄 README.md
📄 index.md
```

看到這個結構就成功了。**不需要再新增或修改任何檔案。**

---

## 步驟 3：產生存取權杖（Personal Access Token）

n8n 要能讀寫你的 repo，需要一把「鑰匙」。

1. 點右上角你的頭像 → **Settings**（注意是帳號的 Settings，不是 repo 的）
2. 左側選單拉到最下面，點 **Developer settings**
3. 點 **Personal access tokens** → **Tokens (classic)**
4. 右上角 **Generate new token** → **Generate new token (classic)**
5. 填寫：

   | 欄位 | 填什麼 |
   | --- | --- |
   | Note | `n8n-wiki`（給自己看的備註） |
   | Expiration | 依課程長度選，例如 90 days |
   | Select scopes | 勾選 **repo**（勾最上面那個大項目，底下會全部一起勾起來） |

6. 拉到最下面點 **Generate token**
7. **重要：** 畫面上會出現一長串 `ghp_` 開頭的字串，
   **這串字只會顯示這一次**，關掉就再也看不到了。
   請立刻複製起來，貼到記事本暫存。

   如果不小心關掉了，回到剛剛的頁面刪掉重做一次就好。

---

## 步驟 4：下載並修改 n8n workflow

1. 在你的 repo 打開 `n8n/llm-wiki-workflow.json`，
   點右上角的下載鈕（Download raw file）把它存到電腦。

2. 用任何文字編輯器打開（記事本、TextEdit 都可以），
   使用「取代」功能（通常是 Ctrl+H / Cmd+H），**全部取代一次**：

   | 找 | 取代成 |
   | --- | --- |
   | `YOUR_GITHUB_USERNAME` | 你的 GitHub 帳號名稱（步驟 1 記下的那個） |

   用「全部取代」讓檔案裡所有位置一起改好。存檔。

   > ⚠️ 帳號名稱是**網址裡那個**（github.com/後面的字），不是你的暱稱或 email。
   > ⚠️ 如果步驟 2 你的 repo 沒取名 `llm-wiki`，把 `llm-wiki` 也全部取代成你的 repo 名。

3. 這份改好的 json 留著，課堂上會匯入 n8n。

---

## 課堂上會做的事（預告）

1. n8n 建新 workflow → 右上 ⋯ → **Import from File** → 選你改好的 json。
2. 匯入後畫面左上角有一張黃色便利貼，照著它把憑證掛上：
   - 每個 **GitHub** 節點：Credential 欄建立一組 GitHub API 憑證，
     User 填你的帳號、Access Token 貼你的 `ghp_` token（只需建一次，其他節點下拉選同一組）
   - **M1 / M2** 節點：Mistral 憑證（API key 課堂提供）
3. 上傳一份小 PDF 測試，回你的 repo 看 `wiki/` 和 `index.md` 有沒有更新。

## ⚠️ 使用須知（請務必看完）

這套流程是**讓 AI 自動寫入你的 GitHub**。GitHub 對自動化行為有偵測機制，
如果被判定為濫用，帳號可能被暫時限制甚至停權。請遵守以下幾點：

### 1. token 絕對不能放進 repo 裡

那串 `ghp_` 開頭的字串等同於你帳號的鑰匙。

- ❌ 不要貼進 `index.md`、`README.md` 或任何檔案
- ❌ 不要貼在截圖裡、不要貼到聊天室或作業區
- ✅ 只貼在 n8n 的憑證設定欄位裡

**如果不小心外洩了**：立刻到 Settings → Developer settings → Personal access
tokens，把那個 token 刪掉，重新產生一個。
注意：光把檔案刪掉是沒有用的，Git 的歷史紀錄裡還留著。

### 2. 不要短時間反覆執行

每跑一次流程，n8n 大約會對 GitHub 發出 4 到 8 次寫入請求。

- 課堂上請**依照老師的指示分批執行**，不要全班同時按
- 執行失敗時，先看清楚錯誤訊息再重試，不要連續狂按
- 兩次執行之間至少間隔一分鐘

### 3. 不要批次上傳大量文件

- ❌ 不要寫迴圈一次丟十幾份 PDF 進去
- ❌ 不要設定排程讓它自動反覆執行
- ✅ 一次一份，看完結果再跑下一份

### 4. 用自己的 token，不要共用

每個 token 每小時有 5000 次請求的額度，各自獨立計算。
全班共用一個很快就會被擋。

### 5. 這是練習用的 repo

- 不要放公司機密文件或個人隱私資料
- 課程結束後如果不再使用，建議把 token 刪掉

**簡單說**：慢慢來、一次一份、token 收好。

## 常見問題

**Q：一定要選 Private 嗎？**
建議 Private。選 Public 也能跑，流程相同。

**Q：repo 一定要叫 llm-wiki 嗎？**
建議照做，這樣 json 只要取代帳號一個東西。取了別的名字就要多取代一個
（`llm-wiki` → 你的 repo 名）。

**Q：token 不小心弄丟了？**
回到步驟 3 的頁面，把舊的刪掉，重新產生一個。舊的刪掉後就失效了。

**Q：token 會過期嗎？**
會，依你設定的天數。過期後 n8n 會開始出現錯誤，重新產生一個換上去即可。

**Q：可以用別人的 repo 嗎？**
不行，你需要有寫入權限。請用 template 自己建一個。

**Q：匯入後節點上有紅色驚嘆號？**
正常，那表示還沒掛憑證。點開節點，在 Credential 欄選你建好的那組就會消失。

**Q：執行時出現 404？**
九成是帳號或 repo 名沒取代對。回到步驟 4 檢查 json 裡還有沒有
`YOUR_GITHUB_USERNAME` 這個字，或 repo 名跟你實際的不一致。
